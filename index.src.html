🎯 按场景挑一个练（点开卡片，一键复制指令）

📝论文改稿 · 导师批注清零▸

把导师在 Word 里留的批注系统化清零：先出清单再动手，避免改漏、防 AI 擅自改。

你是我同课题组的师弟，严谨细心。附件是导师在 Word 里留的 N 条批注（已导出为列表）。 请逐条：①判断批注类型（事实错误／表达／数据／格式／待定）；②给出修改建议与可直接替换的中文； ③标出需要我人工确认的（数值、专业术语、可能的事实问题），不要擅自改。 先输出"批注处理清单"（表格：序号｜类型｜建议｜是否需我确认），不要直接改原文。
🛠 用：WorkBuddy
📚文献速读（3 分钟判断值不值得精读）▸

长 PDF 丢进去，先要"结论＋方法＋创新＋局限"，再决定精读哪篇，省时间。

你是文献助手。下面这篇 PDF／文字是 [文献标题或方向]。 请用 3 分钟能读完的篇幅给我：①一句话结论；②方法核心；③相对已有工作的创新点； ④局限与可借鉴处；⑤3 个值得引用的关键句（附原文页码或位置）。 不确定处一律注明"待核"，不要编造 DOI。
🛠 用：Gemini（长文通读）
🌐中英翻译润色（学术英文）▸

对齐你已有的"论文改稿格式规范.md"：ACS／Elsevier 风格，数值化学式零改动。

你是材料科学方向、母语为英的 co-author。把下面中文译成学术英文，风格贴近 ACS／Elsevier（Applied Surface Science 基调）； 保留所有化学式、数值与单位；难译术语附原文并在首次出现给缩写。 先给术语表，再给译文；译后数值须与原文逐项一致，不一致请标出。
🛠 用：GPT / WorkBuddy
📊数据处理 · 实验记录整理▸

散落笔记／截图，让 AI 整理成规范表格，标出异常值——你只复核。

你是我实验室的助手。下面是 [实验记录／一堆数据]（可贴文本或表格）。请： ①整理成 Markdown 表格（列：样品｜条件｜表征结果｜备注）； ②标出缺失或异常值；③用一句话总结趋势。 严禁编造任何缺失数据——缺失就写"缺"，异常就标"⚠"。
🛠 用：WorkBuddy
🧮数学建模 · 华为杯（你已有 3 人队）▸

你零编程也要能看懂流程图——先讲思路再给可跑代码，不炫技。

你是我数模队的队友（我化工背景、零编程）。题目：[粘贴题面]。请： ①用大白话讲清建模思路与可采用的模型；②给出可运行的 Python 代码框架（带注释，数据用占位）； ③列出论文该写哪几节、每节要点；④给出可用 matplotlib 画的 2–3 张图建议。 代码要能跑、要注释，别堆术语。
🛠 用：WorkBuddy
🧠信息素养大赛 · 答题双轨▸

按你定的规则：有把握的题直接答并给依据；没把握的题改成教你自己查。

我在参加 AI＋信息素养大赛。规则：有把握的题你直接给答案并说明依据让我复核； 没把握的题你改为教我操作步骤（打开哪个网站、点哪里、填什么、看哪个数），让我自己查。 现在这题：[题目]。先判断你是否有把握，再按对应方式回答，不要猜了就选。
🛠 用：WorkBuddy
✍️中文写作 · 小说／材料文案▸

保持已有的人设与节奏，不擅自加设定——尤其《灾变炉心》这种反复改的。

你是我写作的搭档，熟悉《灾变炉心》的设定与人设。任务：[续写／润色／出大纲]。 要求：保持已有的人设、语气与节奏；不擅自加设定；若续写请给 2 个走向让我选。 先确认你对当前情节的理解，再动手。
🛠 用：WorkBuddy / GPT
🔍图表解读（给假设，不装结论）▸

贴数据或描述图，让它讲趋势、给可能原因——原因只是假设，要你验证。

你帮我解读数据。下面是 [数据／图的描述]：_____。请： ①说明整体趋势；②给出 2–3 条可能的原因（明确标注"这是假设，需实验验证"）； ③指出有没有异常点。不要假装这是已证实结论。
🛠 用：WorkBuddy

✍️ 下指令公式（你最该练的）

好指令 = 角色 + 背景 + 任务 + 约束 + 验收。后两条（约束、验收）最容易被漏，偏偏是你最需要的。

角色

你让我当谁（"你是我同课题组的师弟"）。

背景

相关上下文（"在改 Cu(II) 配位聚合物 SCI 论文"）。

任务

具体要我做啥（"把这段中文译成学术英文"）。

约束

格式／风格／边界（"保留数值，不改单位"）。

验收

怎么算对（"译后数值须与表 5.1 一致"）。

⚠️ 避坑

  • 幻觉：AI 会编引用 / DOI / 数据，关键处务必你亲自核对原文。
  • 别当搜索引擎：给背景＋约束它才像同事；只丢一句"查一下"它会编。
  • 隐私：未发表稿件、未公开实验数据、个人信息，别随手传公有模型。
  • 一个文件别让多个模型同时改：防版本冲突（你的硬规则）。
  • 模型会过时：本站排行榜是静态快照，实时排名看各榜单官网。

🎓 TED 英语演讲：提升认知 + 练听力

精选全网公认、播放量极高的 TED / TEDx 经典演讲，主题集中在学习、心理与幸福、习惯自律、沟通与领导力、认知思维五大块。每张卡片都能看到英文标题、中文译名、演讲者、年份、时长、分类和一段中文简介，直接点“看视频”就能跳到官方原片（英文原声 + 可开官方字幕，最适合练英语听力与地道表达）。共收录 0 场，数据整理于 -。

🎧 怎么用最值：① 第一遍关字幕纯听，抓大意；② 第二遍开英文字幕，把听不懂的地方停下来记词；③ 第三遍跟读（shadowing），模仿语调和断句。每天 1 场（10–20 分钟）就够，比刷题更能提升语感和表达。
💡 看 TED 学英语的心法：不要追求“全听懂”——抓住 1 个核心观点 + 3 个地道表达就算赚到。建议准备一个「TED 生词本」，每场只记 3–5 个真正想用的词/句，下一场前先复习一遍。输入够多，输出自然来。
